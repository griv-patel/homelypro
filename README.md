# SIH-homelypro

**Homely Pro** — Cooperative Services Platform connecting verified cooperative workers with households for reliable, affordable, and fair services.

## Overview
Homely Pro bridges the gap between skilled cooperative workers and people who need reliable services across various domains:
- AC Technicians
- Appliance Repair
- Babysitters
- Carpenters
- Cleaners
- Drivers
- Electricians
- Gardeners
- Home Tutors
- Painters
- Pest Control
- Plumbers

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Java / Spring Boot
